## 1. 项目是什么

中南林业科技大学「平安打卡」宿舍签到的**自托管自动化服务**。

- 目标：微信小程序「中南林学工」（appid `wx0e47c34c9982aa09`）
- 形态：一套可自己部署的 Web 服务，含**用户网页**与**管理员网页**
- 技术基础：不是猜接口，而是把小程序从微信 PC 端加密包完整解密、
  解包、逐行还原其 `http/request.js` 签名拦截器后复刻的

## 3. 功能

### 用户网页（`/`）

- 首次使用申请：填学号提交，**必须等管理员亲自批准**
- 绑定学校打卡账号后，系统自动签到
- 每天在 **21:00–22:30** 之间的**随机时刻**执行
- 跟随学校任务的打卡期间（`taskStartDate` ~ `taskEndDate`、`signWeek`），
  **自动覆盖寒暑假**，寒假留校学生照常打卡
- 学校标记「离校 / 请假 / 走读 / 外宿」时自动跳过，不误签
- 日历看板：月视图，绿=成功 / 红=失败 / 黄=待签到 / 灰=无需签到
- 仅凭学号查看：只能查自己的，需学号 + 首次绑定时自设的查询口令

### 管理员网页（`/admin`）

- **有且仅有**管理员本人的账号可登录，其余一律拒绝
- 亲自审批：新用户申请必须手动批准 / 拒绝
- 成员管理：启用 / 停用、重置查询口令、手动签到、撤回授权、删除
- 校历管理：维护学期与假期（**仅用于日历着色**，不决定是否打卡）
- 运行监控：实时统计、今日是否签到、手动触发、失败重试、运行日志

## 4. 技术实现要点

- **签名算法复刻**：相对路径（去掉 query）+ md5 双层签名
- **会话滚动续期**：一次授权后用 refresh_token 长期续期
- **状态码判定**：签到成功后 `signStatus` 仍为 `0`，
  必须看 `signTime` 是否有值才能判断是否已签到
- **定位校验**：提交宿舍基准点自身，距离 0 米
- 技术栈：FastAPI + SQLite + APScheduler，前端零构建原生 JS
- 凭据加密：Fernet 对称加密后入库，密钥部署时随机生成

## 5. 部署方式

### 本地跑起来

```bash
pip install -r requirements.txt
python run.py                       # http://127.0.0.1:8000
```

打开 `http://127.0.0.1:8000/admin`，首次会提示设置管理员账号。
之后把用户端地址发给同学，同学提交申请，管理员批准即可。

### 部署到云服务器

```bash
python tools/deploy_remote.py --host <你的服务器> --user root
# 默认装到 /opt/autosinin，可用 --remote-dir 改路径
```

一键完成：预检环境 → 打包上传 → 装依赖 → 建专用用户 → 配 systemd → 启动验证。

要点：

- 服务器需在**中国大陆**（否则访问不了学校接口）
- 时区设为 `Asia/Shanghai`（签到窗口按此时区计算）
- 抓包工具打包：`python tools/build_classmate_kit.py`
  产出 `dist/checkin-auth-tool.zip`（免安装，内置 Python 与 mitmproxy）

### 授权采集流程

学校账号普遍开了短信二次认证，无法直接用账号密码登录，
需要使用者在小程序里授权一次、抓取会话令牌：

1. 把分发包发给同学，解压后双击 `1-start.bat`
2. 完全退出微信，重新打开，进入小程序打卡页
3. 双击 `2-finish.bat`，生成结果文件发回给部署者
4. 部署者一条命令导入：
   ```bash
   python tools/read_token_file.py "路径/token-result.txt" --host <你的服务器>
   ```

## 6. AI 辅助部署

仓库文档齐全、命令固定，可以直接把仓库交给 AI 编程助手（Claude Code、
Cursor、Codex 等）来部署。推荐做法：

- 让 AI 先读 `README.md` 与 `docs/DEPLOY.md`
- 自检工具：`python tools/verify_all.py`（单元 + 端到端 + 静态检查）
- 一致性核对：`python tools/check_server_sync.py`（比对服务器与本地代码）
- 隐私自查：`python tools/audit_privacy.py`
- 部署前探针：`python tools/preflight.py --online`

## 7. 需要诚实说明的限制

- 接口可能变更 —— 学校升级系统后本项目可能立即失效
- 不保证签到成功；真实情况是**靠学校接口的返回判断**
