# 同学授权采集（抓包录入 token）

## 为什么需要这一步

网页端想代同学签到，必须先拿到该同学在学校的**会话凭据**。可选方案只有两个：

| 方案 | 可行性 |
|---|---|
| 学号 + 密码，服务端换 token | ✗ **不可行** —— 学校账号启用了短信二次认证（`isSysUserSecondAuth: true`），`grant_type=password` 会撞上二次认证 |
| 抓取同学在小程序里的登录会话 | ✓ 唯一可行路径 |

所以流程是：**同学在小程序里登录一次 → 我们抓取那一次的 token → 加密入库长期复用。**

抓到的 token 实测有效期约 **18–20 天**，到期后需要重新采集一次。

---

## 操作流程（管理员视角）

在**你自己的电脑**上执行：

```bash
python run.py                              # 先启动服务
python tools/token_catcher.py 20240001     # 学号可选，留空则抓完再问
```

工具会依次：

1. **提示风险并等你确认** —— 说明会临时安装证书，需要你输入 `yes`
2. 把 mitmproxy 的 CA 装进【当前用户 → 受信任的根证书颁发机构】
3. 启动本地代理（`127.0.0.1:8888`）并接管系统代理
4. **把电脑交给同学**，让他：
   - 完全退出微信（托盘右键 → 退出，不是关窗口）
   - 重新打开微信 → 进入「中南林学工」→ 登录
   - 点进底部「打卡」页，停留 5 秒
5. 抓到 token 后**自动卸载证书、关闭代理**
6. 用该 token 拉取打卡任务做校验，失败则不录入
7. 生成**查询口令**并打印，同时把 token 加密写入数据库

结束后你会看到：

```
  学号       : 20240001
  姓名       : 张三
  查询口令   : K7M2QP
               ↑ 请转告该同学，用于登录本系统查看自己的签到情况
  签到时刻   : 21:47（窗口 21:00-22:30）
  宿舍       : DY06（原23） 407
  凭据有效期 : 约 18 天，到期后需要重新抓一次
```

---

## ⚠️ 为什么必须"完全退出微信再打开"

微信 PC 客户端**只在启动时读取一次系统代理**。不重启的话，流量仍然走直连，
抓不到任何东西 —— 这是最常见的失败原因。

## ⚠️ 为什么必须点进「打卡」页

小程序只有部分页面会带认证头发请求。首页、我的页面可能都用缓存数据；
**「打卡」页一定会调 `getTaskByIdForApp`**，那才是带 `FlySource-Auth` 的请求。

---

## 常见失败原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 一直等待，抓不到 token | 微信没完全重启 | 托盘右键彻底退出后重开 |
| 小程序里显示「网络错误」 | CA 证书没装上 | 重新运行工具，确认证书安装步骤成功 |
| 抓到 token 但校验失败 | 同学没真正登录，或 token 已过期 | 让同学确认能正常看到打卡页后再试 |
| 同学用的是手机 | 手机抓包需要另一套流程（代理+证书装到手机） | 建议改用本机微信 PC 端登录 |

## 多同学批量录入

逐个运行即可，每次会重新装/卸证书。也可以加 `--keep-cert` 在批量采集期间保留证书
（采完记得手动执行 `python tools/install_ca.py uninstall` 移除）。

每位同学的 `plan_sign_time` 会在录入时于窗口内**随机分配**，
所以大家的签到时刻是分散的、不可预测的。

---

## 安全说明

* 证书只装进**当前用户**存储，不写系统级存储
* 需要你**显式按回车确认**才会安装，不静默操作
* 采集结束**自动卸载**证书并关闭代理
* 原系统代理设置备份在 `tools/proxy_backup.txt`
* 抓到的 token 立即用 Fernet 加密入库，**不落明文**；
  `tools/capture/` 目录已加入 `.gitignore`
* 采集期间本机处于"HTTPS 可被本机解密"状态，**不要让同学在本机登录网银等敏感账户**
* 采集前会提示你，采集后会恢复；如中途强行中断，手动执行：
  ```bash
  python tools/system_proxy.py off
  python tools/install_ca.py uninstall
  ```
